## How I verified

- Same method as the 2026-11-05 pass. `yt-dlp` 2026.10.21 with `--skip-download -J` on each watch page (live read, metadata only) and `ytsearch` in flat mode for discovery. No video, audio or caption files were downloaded.
- Every URL below came back from a live watch-page read today with the title and channel matching. Upload date, length, views, chapter list and caption track list are straight from that read. Length can differ from the listing by one second.
- "Caption track present" means the track list on the watch page. I did not read the text and saved none.
- Version rule. Only a version written in the title, description, or channel page counts as stated. Otherwise "not stated" plus an INFERRED guess from upload date. I did not watch any video, so every INFERRED version stays unverified.
- "Needs paid add-ons or assets" is from the description text and the chapter list only. I did not watch the videos, so a paid tool used on screen but not named in the description would be missed. Marked UNVERIFIED where that matters.
- Excluded channels from the earlier pass were not used for the boat search. For sci-fi I did not need them, the only Ryan King Art item seen was a "creation process" showcase, not a tutorial.
- A first sci-fi candidate, The Smugglers Room "Easy Spaceship Modeling Techniques!", turned out on its description read to be physical Star Wars model kitbashing, not Blender. Dropped. This is the reason every pick was opened, not trusted from the title.
