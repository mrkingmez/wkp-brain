# Long tasks: files, chats and memory

About 12 minutes to read, plus about 45 to do the practice

## What you will be able to do

- Work on one document over several messages, instead of one giant prompt.
- Hand a document to the AI two ways: by attaching it, or by pasting the text.
- Carry a job from one chat to another with a handoff note, without relying on any memory feature.

## What you will make

A summary, an action list, and a draft reply, all built from one document across several messages. Then a "handoff note" that lets you start a fresh chat and pick the job up where you left off. The document is a made-up neighborhood newsletter, so there is nothing private in it.

## Big jobs go in small steps

You already know one message can be vague or clear. Here is the next skill: a big job is rarely one message. A long document, a messy pile of notes, a project with several parts. These work best as a conversation.

A good pattern for a long job:

1. **Give it the material.** The document, the notes, the list.
2. **Ask for a small first step.** A summary, or a list of the main points.
3. **Check that step.** Does it match what you know is in the material?
4. **Ask for the next step, building on the first.** Actions, a draft, a comparison.

Each step is small enough to check, and each one builds on the last. If something goes wrong in step two, you catch it before it spreads into steps three and four.

## Two ways to hand over a document

**Paste it.** Copy the text, paste it into the message box, and say what you want done with it. This works in any chat tool. It is the way to rely on.

**Attach it.** Many chat tools let you attach a file, such as a PDF or a Word document, using a button near the message box. Whether your free Claude or free ChatGPT offers this, which kinds of files it takes, and how big a file can be, depends on the plan and changes over time. **Check this yourself** on the company's own pages, and write down the date you looked.

## A chat is a thread, and threads wear out

Each chat is one long thread. The AI reads what is in the thread to answer your newest message. That is why follow-ups work so well. But there are limits, and they are worth knowing about.

- **Long chats can drift.** After many messages, early details may get less attention. If the AI starts forgetting something you said at the start, that is a sign the chat has gotten long.
- **There is a limit to how much a chat can hold.** The size depends on the tool and the plan. We will not guess at it. Look for it on the help pages above.
- **A new chat starts empty.** By default, a new chat does not know what you said in an old one. That is why you will learn the handoff note below.

## What about memory

Some chat tools have a memory feature that carries a few facts from one chat to another. Whether yours does, whether it is on by default, and how you turn it on or off, are things that change and differ between Claude and ChatGPT. **Check this yourself** in the settings and help pages, and note the date.

Two things hold no matter what the answer is.

- Do not count on memory. It may be off, it may be wrong, and it may remember something you would rather it did not.
- Anything you do not want kept should stay out of the chat in the first place.

A handoff note works on every tool and needs no memory feature. That is the skill to learn.

## The handoff note

When a long job needs a fresh start, or you come back the next day, do this.

1. In the old chat, ask for a handoff note: a short summary of the job, what has been decided, and what is left to do.
2. Read it. Fix anything wrong. You are the one who knows what is true.
3. Open a new chat and paste the note as your first message, then say what you want next.

It is like writing on a sticky note for tomorrow's you.

## Keep this in your pocket

1. Big jobs go in small, checked steps. Give the material, ask for a first step, check it, then build.
2. Pasting text works everywhere. Attaching files and memory differ by tool and plan, so check the company's pages yourself.
3. For a fresh start, ask for a handoff note, fix it, and paste it into a new chat.

## Practice

Three jobs, about 15 minutes each. Use claude.ai. You will also need a Google Doc (go to docs.google.com, sign in, and click the Blank document tile). Use only the made-up document below. Nothing private.

### Task 1: Make your practice document

**Why it matters:** real practice needs a real-looking document, and a made-up one keeps every private detail out of the chat.

**Do this:** in a new Claude chat, ask it to write the document below. Copy the result and paste it into a new Google Doc. Name the Doc "Practice newsletter". Keep it. You will use it in Tasks 2 and 3.

```text
Write a made-up one-page newsletter for a small neighborhood association called Maple Court Neighbors. Include a message from the president, a note about a trash pickup change, an invitation to a Saturday potluck with a sign-up request, a reminder about a pool closing date, and a request for volunteers to help paint the mailbox shelter. Use made-up names and dates. About 350 words.
```

**Self-check:**

- [ ] The newsletter has at least five separate items in it.
- [ ] It uses only made-up names and dates.
- [ ] I saved it in a Google Doc with a name I will recognize.
- [ ] I read it once so I know what is in it.

**What good looks like:** a one-page newsletter with several different items, each with a date or a request. The items matter, because the next task asks you to find them again.

---

### Task 2: Work through it in steps

**Why it matters:** this is the real pattern for any long job. Small steps, each one checked.

**Do this:** open a new Claude chat. Paste the first prompt with your newsletter text pasted in where it says. If you see an option to attach a file and want to try it, you may, but pasting is fine. Read the answer and check it against the Doc. Then send the second prompt, then the third, in the same chat, checking each before the next.

```text
Here is a newsletter. First, give me a summary in five bullet points.

[paste your newsletter text here]
```

```text
Now list every date and every request in the newsletter as a checklist, one line each, with who is being asked to do what.
```

```text
Now draft a short, friendly reply from me to the president. I will bring a dish to the potluck, and I can help paint on one Saturday. Do not invent a dish or a date I did not give you.
```

**Self-check:**

- [ ] I checked the summary against the Doc before I moved on.
- [ ] I made sure the checklist did not miss an item or add one that is not in the newsletter.
- [ ] I read the reply for details I never gave, such as a dish name, and removed them.
- [ ] I can say which of the three steps was easiest to check, and why.

**What good looks like:** a summary, a checklist, and a draft reply that all match the newsletter. If it missed a date or invented one, tell it, "You missed the pool closing date. Add it." That correction is the work. If it asked a question back, such as which dish, answer it. That is the AI being careful, and it is a good sign.

---

### Task 3: Write a handoff note and start fresh

**Why it matters:** you will leave a chat mid-job many times. This is how you come back without starting over.

**Do this:** in the same chat as Task 2, send the first prompt. Read the note and fix anything wrong. Open a new chat (click New chat at the top left, or the plus sign if you see one), paste the note as your first message, then ask the follow-up in the second prompt. See whether the new chat can continue with only the note.

```text
I need to stop here and continue in a new chat. Write a short handoff note I can paste there. Include: what the document is, the five main points, the checklist of dates and requests, what I decided to do, and what is still left to do. Keep it under 200 words.
```

```text
Using only the note above, remind me what I still need to do, in order, and suggest which one to do first.
```

**Self-check:**

- [ ] I read the note and fixed any error before pasting it.
- [ ] The new chat's answer matched the newsletter and my decisions.
- [ ] I noticed anything the note left out that the new chat then could not know.
- [ ] I saved the note in my Doc, below the newsletter.

**What good looks like:** a new chat that picks up the job from the note alone. If it misses something, the note was missing it, so add that line to the note and try again. A handoff note is a draft you improve. Keep this one. You will turn jobs like it into saved prompts in the next lesson.
