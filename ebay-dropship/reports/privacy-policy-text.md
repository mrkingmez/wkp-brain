# WKP Commerce Privacy Policy

Last updated: October 19, 2026

WKP Commerce is a private tool run by Warrior King Productions in Georgia, USA. It is used by one person, the owner, to manage his own eBay seller account.

**What it accesses.** The tool connects only to the owner's own eBay seller account. It reads and manages that account's listings and orders.

**What it collects.** It does not collect personal data from buyers, visitors, or any other person. Buyer details that eBay provides with an order are used only to fulfill that order.

**What it shares.** Nothing is sold or shared with anyone else. Order details go only to the supplier that ships that order.

**Storage.** Access keys are stored on the owner's own computer. No data is stored on a public website.
