# Pre-flight: Firefly or Veo/Kling/other video prompt card with settings.txt

Created 2026-11-22 by graphic-design. Same hand-back rule as the image card.

1. [ ] Lint PASS or an explained WARN on the prompt file. Paste the line.
2. [ ] Engine and tier named, the maker's template used (Veo: cinematography, subject, action, context, style then audio sentences, G2). Proof: one-line mapping.
3. [ ] One body, one object, one action per clip. Handoffs and swaps are two clips and a cut. Count the actions in writing.
4. [ ] Start frame named and how it was made. With a start frame the prompt is motion only (R2, F3). Geometry, side, logo and tool shape live in the picture. Hand and side are camera-relative words.
5. [ ] Contact, landing or "ends resting against" has an end frame written, or a cut is planned. If the panel has no End slot, mark "Zac checks the panel", never assume.
6. [ ] One camera sentence using maker terms (static, locked-off, POV, dolly, push in), compatible with the action. A traveling body gets a cut or a following camera.
7. [ ] Audio decided: off in the panel with no audio words, or `SFX:` and `Ambient noise:` lines. Never "no music".
8. [ ] Timing as continuous ranges or plain verbs, no point times on Veo, no slow motion unless asked.
9. [ ] No unwanted thing is named anywhere, no contradiction, no "as if", "seems", "mood" or "begins to".
10. [ ] settings.txt top block filled, every field present (NOT SHOWN where the panel does not show it), blanks for Zac. Credit readout is Zac's field. No credit number anywhere. Draft size is the cheapest that shows the idea.
11. [ ] Every instruction tagged SOURCED (maker quote and id), PROVEN (log path and count) or PROPOSED, with a cheapest test for each PROPOSED one.
12. [ ] Log folder name is written on the card (it is made when run).
