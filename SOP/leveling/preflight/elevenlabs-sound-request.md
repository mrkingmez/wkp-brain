1. [ ] The exact cost is written (credits and plan month), taken from a retrieved page, or "NOT RETRIEVED". No estimate stated as fact. Proof: URL and date.

4. [ ] The prompt names no artist, song, album, label or distinctive lyrics (Music Terms prohibit it). Proof: scan the prompt text.
5. [ ] Genre, mood, instruments, tempo as a number, key, "instrumental only" and the length are in the prompt. PROPOSED unless we have a logged result: say so, and give the cheapest test (the shortest allowed length, one take). Proof: prompt text and tags.
6. [ ] The ElevenLabs output is labelled for platform AI-disclosure rules (Section 4.4), and Free-plan output needs attribution. Proof: line in the card.
7. [ ] An owned fallback cut exists at the same length, with its license status, so the job never waits on the spend. Proof: path.
8. [ ] A license log row is ready per kept file: date, plan on that day, model, prompt, credits, and a screenshot of the plan page (rights stay with the plan at creation, Section 1.5). Proof: row template filled except the result.
9. [ ] Generations are one at a time. "Never repeat a generation call to retry" (the connector rule). Proof: the plan states one call per take.
10. [ ] Sound effect requests (not music): the SFX licence page is NOT RETRIEVED, so SFX output carries "license text not read" until Zac or an agent reads it. Proof: label.
