# Pre-flight: Sting or intro cut (wwd-vfx)

Run before hand-back, paste with each item ticked and one line of proof. Built 2026-11-22 from the 6 s rule (`memory\feedback-intro-length.md`) and the credit failure (LESSONS F1 to F6).

1. Length is 6.000 s or less for an intro sting (ffprobe pasted). Outro length stated and chosen, not copied from an old brief.
2. 1920x1080 and 30 fps for video pieces, audio 48 kHz (ffprobe pasted).
3. Peak below -1 dBTP before it goes into an edit (measured with ebur128 true peak, number pasted). The raw A Knight's Tale outro peaked +0.2 dBFS, so check.
4. Ends on a fade or a hit tail, not a hard cut (last 0.5 s level pasted).
5. Free route first: the piece is code-built or composited from owned footage unless the director says a generation is needed, and the hand-back says why a generation is needed.
6. If a generation is needed: Zac is shown the exact credit cost read at the Generate button (NOT KNOWN until then, never estimated), the cheapest model test is offered first (Fast or Lite model, shortest duration, lowest resolution), and no run happens without his yes.
7. Prompt is short, literal, pins the start frame in the first sentence, never names an unwanted object or action (F1, PROVEN), never asks for left or right placement in text (F5, PROVEN). Composition lives in the start frame.
8. The start frame has the real logo composited on a rectangular shield, never a logo on black (F3, partly PROVEN, 3 clips versus 2).
9. Recipe recorded: model tier, resolution, aspect, fps, duration, audio on or off, seed, start-frame path, and a settings.txt beside the clips (none of the 18 logged clips has one).
10. No studio logo, font or art. No music except intro and outro. Sounds owned, path named.
11. Every instruction tagged PROVEN, SOURCED or PROPOSED, PROPOSED ones with the cheapest test named.
12. Ledger row states credits spent (0 or the amount Zac approved, as retrieved).
