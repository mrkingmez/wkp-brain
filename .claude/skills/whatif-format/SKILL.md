# What If - Format A

Formerly called "Watershed". That name is RETIRED. Method unchanged.
Full SOP: D:\WKP\WKP-CHANNEL\Watershed-SOP-v3.md
Model: D:\WKP\WKP-CHANNEL\models\Watershed-Predictive-Model.xlsx

## What defines this format
A forward-looking predictive branch model from a real historical fork.
Not a narrative guess. The machinery is the product.

## NEVER MIX WITH HIDDEN HINGE
A predicts FORWARD from an open fork. B re-traces BACKWARD through a
resolved chain. Do not build branch-probability machinery into a
Hidden Hinge episode. It needs a causal-dependency case, not a
percentage.

## The nine steps, in order

1 Baseline Reconstruction - the real trajectory, fully sourced. You
cannot model a divergence from a point you have not established.

2 Variable Identification - political, military, economic, personal
factors at the divergence point. Primary sources: memos, orders,
declassified cables, recorded conversations. Not general summaries.

3 Reference Class Forecasting - find analogues. Other moments where a
similar leader or system faced a similar fork, and how they actually
resolved. This is the step that separates forecasting from guessing.
Anchor in a real base rate.

4 Branch Construction - 2 to 3 explicit branches, each conditioned on
NAMED variables. Never "maybe this, maybe that."

5 Score It - open the spreadsheet. Per variable: Importance 1-5,
Confidence 1-5, Branch Support 1-5 per branch. The sheet computes
weighted scores and normalized percentages. Study the JFK Example tab
before building a new one.

6 Devil's Advocate - route to devils-advocate, aimed at the
HIGHEST-scoring branch specifically. Attack its weakest assumptions
deliberately. Survives, confidence rises. Does not, adjust and
recompute.

7 Sensitivity Check - zero out one factor's Importance and watch the
movement. A factor that swings the result is LOAD-BEARING. Name it on
screen. Hiding it makes the model persuasive instead of honest.

8 Trace Forward - highest-probability branch, explicit checkpoints.
Five year mark with up to three specific developments, then outward.
Reference back to which Step 2 variables drive each development.

9 Verdict as MODEL OUTPUT, not opinion. On screen this reads "our
model weights this branch at roughly 37% against two competing
branches near 31% each, driven primarily by [load-bearing factor]."
Never "here's what probably happened." Show the machinery.

## Optional segment - the other side could have won

Not mandatory. Only where the counterfactual is genuinely strong.
Must be built from real capability the losing side actually had at
that moment - position, timing, assets, decisions on the table. No
modern tactics transplanted backward.
Labeled [SPECULATIVE] on screen. It is reasoning, not research.
Use the Causation Test in reverse: shortest defensible chain that
flips the outcome. Shorter chain, stronger segment. Say so honestly
when the chain is long and weak.
Forcing this into an episode that has not earned it produces a
fabricated branch - the exact failure the research rules exist to
prevent.
