# Fiction Alpha Feedback

## What this is not

Not an editor. Does not suggest prose fixes, does not recommend a
decision. Turns scattered notes into one document Zac marks up.

## Input

One raw feedback document per reader, using the Alpha Feedback
Template (see bottom). Read every one in full before writing
anything. A partial read is not a read.

## Canon

Read the full Book Guide before touching any feedback - whatever the
director points at. This skill carries no canon of its own, same as
fiction-editing.

## Process

1. Read every reader's document in full.
2. Read canon in full.
3. Group notes by chapter, then by location, anchored to the
   reader's quoted line. If two readers quote different lines but
   are clearly flagging the same moment, group them and say why.
4. Check each group against canon. Three outcomes only: Consistent,
   Conflicts (name the fact and where it was established), or No
   canon implication.
5. If two or more readers independently hit the same spot, that is
   the strongest signal in the document. State the count plainly,
   first thing in that entry, not buried in reader order.
6. Never recommend a call. State what was said and what canon says.

## Output

One worksheet per round, chapters ascending.

    # Alpha Feedback Worksheet - [Book] Round [N]
    Readers: [names]. Deadline: [date].

    ## Chapter [N] - [title if known]

    ### [Location, anchored to a quoted line]
    **Flagged by:** [names] - state the count if 2+
    **[Reader]:** [what they said]
    **Canon check:** [Consistent / Conflicts with X, Chapter Y / No
    canon implication]

    **Zac's call:**
    [ ] Accept as suggested
    [ ] Reject, keep as written
    [ ] Modify - direction: ______________________
    [ ] Discuss with Matt / readers first

## Save location

Shattered Empire: D:\WKP\SHATTERED-EMPIRE\alpha-feedback\book[N]-round[N]-worksheet.md
Sci-Fi: D:\WKP\SciFi-Novel\alpha-feedback\ same pattern

## Rules

No em dashes. Never paraphrase a reader's note into something
softer or harsher than what they actually wrote.
If a reader's document doesn't follow the template and a location
can't be anchored to real text, say so for that entry and ask rather
than guessing the spot.

## Escalation

Canon itself unclear on a point a reader raised - that's Needs
Author Confirmation, not Conflicts. Say so, don't force a side.
