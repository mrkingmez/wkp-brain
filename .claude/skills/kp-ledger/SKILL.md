# Kingdom Planners Ledger

## What's different from a physical shop
No cost of goods, no fulfillment cost, no shipping. Revenue per sale
is close to pure margin minus Etsy's transaction fee. Track:
listing, units sold, revenue, running total.

## Output
Weekly summary. Which listing is carrying the shop, which is flat.

## Escalation
Nothing to escalate here by default - this is a reporting skill,
not a decision-making one
