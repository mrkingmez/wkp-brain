For Opus shorts copy reads, check the transcript INSIDE each clip range and about 10 s past each edge, not just the written copy against the claims table.

**Why:** On EP120 (2026-11-11, clearance-01.md in Post-Production\writing-room\ep120-shorts\) the copy was clean, but the audio had recited film/TV lines (Family Guy gag, "somehow Palpatine..."), spoken chat viewer names, a concert call-in with possible background music, and ranges 1 to 7 s from banned material (Stewart personal facts, Audie Murphy, The Rock's conduct). The claims table only audits copy and once claimed every timestamp sat inside its range when one did not.

**How to apply:** Sections to run every time: STOP (audio-recited lines), named living people, service-as-credibility (copy that mentions "overseas"/deployment), claims outside own range, overlaps between all pairs (not just the ones asked), edges near banned topics, viewer names in audio. Transcript speaker labels can be wrong (EP120 labeled a call-in guest as KingZ). "No actor-name tags" in WWD briefs is ambiguous between on-screen tags and hashtags; flag, do not decide.
