## 2. Resolving the tension with the one-sponsor-line layout

Standing rule (WWD-2026-11-05-05, adopted by Zac per Jarvis): Surfshark on description line 1, at most 1 other link, sponsor-only pinned comment, no sponsor links on Shorts. Note: `logs\DECISIONS.md` still shows that row as OPEN. Jarvis should update it.

Evidence behind it (`research\wwd-monetization\links-per-video.md`): among 15 channels, every sponsored large-channel video carried exactly 1 sponsor link on line 1 and nothing commercial competing with it. 0 of 14 recent Shorts carried a third-party link.

How Opus fits:

| Place | Rule | Opus |
|---|---|---|
| Regular review or FrostCast description | Surfshark line 1, at most 1 other link | Opus does NOT use the "other link" slot. No Opus mention on regular videos. |
| Regular pinned comment | Sponsor only | No Opus. |
| Shorts (any) | No sponsor or affiliate link | No Opus link, ever. The pointer sentence (Section 3G) is HELD and devils-advocate says kill it. |
| The one how-to video | One commercial link | Opus takes the single slot on line 1 with the disclosure on the same line. Surfshark line is dropped on this video only. Pinned comment carries the Opus link. This is a named exception. |

Fallback if the Surfshark agreement turns out to require its link on every video (NOT verified, the September attorney question is still open in TASKS.md): Surfshark stays on line 1, Opus goes on line 2, each with its own disclosure in the same line. That puts two affiliates on one video, which breaks the "nothing competing" norm, so use it only if the contract forces it.

Why not use the "1 other link" slot on every video: that is the exact creep devils-advocate warned about. Mentions on reviews, on-air plugs and public stories about past mistakes are where trust gets spent.
