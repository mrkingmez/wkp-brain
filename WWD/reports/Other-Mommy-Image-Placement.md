## Fun transitions for the posters (added 2026-10-13)

Zac's call: one creepy transition in every report to keep it entertaining. Melt on the open poster (#1), blood on the close poster (#16). The opening has a burning logo after the intro line (about 00:14 to 01:31 on your timeline, the Premiere transcript shows no speech there), so the poster only covers the intro line and the melt hands off to the logo. Both are built from stock Premiere effects. Effect names are written from knowledge, not checked against your build, so search the Effects panel by name if one moves.

### Melt Away (open poster, #1)
1. Put the poster on the track above the host cams, 00:01 to about 00:14 (the intro line only). The melt happens on its last 30 frames, so the poster dissolves as the burning logo takes over. Trim the poster's end to where the logo starts.
2. Drag **Turbulent Displace** onto it. Displacement: Twist, Size about 40, Amount 0.
3. Drag **Wave Warp** onto it. Wave Type: **Smooth Noise** (the options are Sine, Square, Triangle, Sawtooth, Circle, Semicircle, Uncorrelated Noise and Smooth Noise, and Smooth Noise gives the organic, melty wobble). Direction 0, so it ripples vertically.
4. Drag **Linear Wipe** onto it. Wipe Angle 180, Feather about 25%. The 180 angle runs top to bottom so it drips away instead of fading flat.
5. Keyframe over the last 30 frames: Turbulent Displace Amount 0 to about 120, Linear Wipe Transition Completion 0% to 100%, Opacity 100% to 0%.
6. Play it back. If the melt is too violent, lower the Amount.

### Blood Ooze Away (close poster, #16)
1. Poster on V2. Project panel, right-click, New Item, Color Matte, dark red (about 7a0000). Put it on V3 above the poster, same length.
2. Keep the blood on the poster only (Zac hit this 2026-10-13: Multiply on a full-frame matte tints the host cams too). Drag **Crop** (Video Effects, Transform) onto the red matte. Set **Left 31.25%** and **Right 31.25%**, Top and Bottom 0. The poster PNG is 720 px wide centered in the 1920 frame (pixels 600 to 1320, full height), so this trims the red to exactly the poster. The hosts stay clean. If you scaled the poster in the timeline, adjust Left/Right to match. (Track Matte Key with Matte Alpha also works, but its Matte list showed only None on Zac's build, so use Crop.)
3. Set the red matte's Blend Mode to **Multiply** (Effect Controls, Opacity) so the poster detail shows through the blood. With the matte in place it only multiplies over the poster. If Multiply still looks wrong, use Normal at about 85% Opacity.
3b. Drag **Linear Wipe** onto the red matte (after Track Matte Key in the effect list). Wipe Angle 180, Feather about 15%.
4. Keyframe Transition Completion from 100% to 0% over about 36 frames. The red runs down over the poster from the top.
5. Optional: low-Amount **Turbulent Displace** on the red matte for ragged drip edges.
6. End of the clip: 12 frame **Cross Dissolve** across the stack to hand off to the host cams.

### Shortcut
Any free blood-drip or ink-bleed overlay clip from a stock site. Put it above the poster, Blend Mode Multiply, and line it up with the poster's last frames. Needs a clip you supply.

## How to apply in Premiere

1. The timecodes are for your edited sequence. Drop each image on the track above the host cams at the start timecode and trim to the end timecode.
2. Effects panel, Video Transitions, drag the named transition to the head or tail of the clip. Right-click it, Set Transition Duration, and type the frames.
3. For hard cuts, no transition. The PNGs have transparent padding, so the host cams show behind the image.
4. Spot-check one or two placements against the audio first. If the drift is more than a couple of seconds, shift all of them by the same amount.
