# Identified Biases — Accuracy Tracker

Running list of patterns found in graded predictions and whether a fix
has been applied. Written by a human reading the weekly report, not
generated automatically — see ACCURACY-TRACKER-BUILD.md: "It is not a
learning system. Nothing here trains automatically."

Format per entry:
```
## YYYY-MM-DD — short description
Pattern: what keeps going wrong, with the numbers behind it
Fix applied: what changed (rule, model input, nothing yet)
Result: did it work, checked against how many weeks of data
```

Empty until Phase 1 has graded enough real weeks to see a pattern.
