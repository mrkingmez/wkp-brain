**Why:** originality has failed: spoiler-motive villains (Henry Danger, Simpsons), object-for-a-head figures (Skibidi Toilet), fog + flashlight + tall shape (Silent Hill), Oracle as camera/scanner/headset hub (Barbara Gordon), villain wanting "everyone stays in role" (Lord Business, Truman Show).

**How to apply:** avoid all of the above. Oracle (Gabby) faceless until she OKs a likeness, no headset or lens eye. Only Oracle says numbers, Wolf gives verdicts, KingZ asks (max one joke an issue). Balloons 12 words or fewer, 4:5 slides, pages split in two by default. Always write to a new filename; never reuse a draft path another run might hold.
