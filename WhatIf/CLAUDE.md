## The Two Formats — Locked Definitions

FORMAT A — "WATERSHED"
A single major event that changed the world, for better or worse. Not battle-exclusive; JFK surviving Dallas is the model case, but a battle qualifies if it is a genuine fork with predictive-branch structure (for example, Midway going to Japan). The defining feature is a forward-looking predictive branch model from a real historical fork.

FORMAT B — "HIDDEN HINGE"
Specifically battles and military events. Not a branching prediction — a backward-looking causal-chain correction. "You were taught battle X mattered because of outcome Y. Battle Z, same era, actually drove more of Y. Here is the dependency chain, and here is what happens to X if Z goes differently."

THE DIFFERENCE THAT MATTERS: A predicts forward from an open fork. B re-traces backward through a chain already resolved. Do not build A's branch-probability machinery into a B episode. B needs the causal-dependency case, not a percentage.

## Format A Process — 9 Steps
1. Baseline Reconstruction — document the real historical trajectory first, fully sourced. Cannot model a divergence from a point not accurately established.
2. Variable Identification — causal variables active at the divergence point: political, military, economic, personal/leadership. Pull from primary sources — memos, orders, declassified cables, recorded conversations, contemporaneous reporting. Not general summaries.
3. Reference Class Forecasting — find historical analogues and see empirically how they resolved. This is the step separating a real method from a guess. Anchor in an actual base rate.
4. Branch Construction — 2 to 3 explicit branches, each conditioned on specific named variables. Not "maybe this, maybe that."
5. Score It — open the spreadsheet. Per variable: Importance (1-5), Confidence (1-5), Branch Support (1-5 per branch). Weighted score and normalized probability compute automatically.
6. Devil's Advocate Stress Test — attack the highest-scoring branch's weakest assumptions on purpose. Adjust and recompute if it does not survive.
7. Sensitivity Check — zero out one factor's Importance and watch the shift. A factor that swings the result is load-bearing and must be named on-screen, not hidden.
8. Trace Forward with Checkpoints — 5-year mark with up to three specific developments, then outward. Keep referencing which Step 2 variables drive each development.
9. State the Verdict as a Model Output, Not an Opinion — "our model weights this branch at roughly 37% against two competing branches near 31% each, driven primarily by [load-bearing factor]." Show the machinery.

## Format B Process
Use the Hidden Hinge Worksheet tab. Eight questions, not a branch model:
1. The famous battle (X) — what outcome is it credited with?
2. The overlooked battle (Z) — what actually happened?
3. What factors drove Z's outcome?
4. How does Z causally feed into the conditions that produced X?
5. If Z had gone differently, does X still happen, happen differently, or never happen?
6. through 8. — see the worksheet.

## Hard Rules
- Every factor needs a real, cited source. No unsourced assertions in a model.
- Never present a model output as an opinion, and never present an opinion as a model output.
- Never mix Format A machinery into a Format B episode.
- The scores in the JFK Example tab are illustrative starting values, not research conclusions. Replace before publishing.
- This is a transparent elicitation framework, not a machine-learning model. The rigor comes from sourced inputs and visible weights, not from the arithmetic. Do not overstate what it is.
