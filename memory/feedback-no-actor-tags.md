Zac does not put actor tags (name labels) on pictures in WWD reviews and decided on 2026-11-07 that he does not need them.

**Why:** He was confused by "Actor tag only" in the Godzilla run sheet (it meant the tags.md cast note, not an on-screen graphic). I recommended against starting them, he agreed.

**How to apply:** Do not add name tags or lower-thirds to run sheets, and do not build a tag kit piece. In run sheets, say plainly when a note refers to tags.md (for example "tags.md gives the actor only, no character"), never bare "actor tag". See [[wkp-ops]].
