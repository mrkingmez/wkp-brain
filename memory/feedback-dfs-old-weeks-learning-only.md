Once a DFS week is over, any deliverables are done. Old weeks are reopened only to learn from them and build the learning database, never as open items or missing-file chases.

**Why:** Zac, 2026-11-22, when I checked Week 10 DFS files as a "missing results" claim: "there is no reason to look back at old weeks for Dfs unless you are using it to learn from and build that database of information. but after the week is over any due outs are done."

**How to apply:** Do not list old-week DFS results, files or gaps as open or unverified. Agents gap-auditing DFS use past weeks as learning data only and do not flag a missing Week N file as a problem. Weekly learning goes in the ledger (see [[project-dfs-learning-goal]]). DFS only, never IRFL. See [[feedback-lead-decide-autonomy]].
