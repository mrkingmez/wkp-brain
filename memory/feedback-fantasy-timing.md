Do not run the fantasy football cycle (picks, sims, lineup) early in the week. First full run is after Wednesday practice reports. Zac, 2026-11-04: "never run it before wednesday practice reports", after Week 9 was run Tuesday night.

Then rerun Thursday morning, and again whenever new info lands (practice reports, injury news, line moves). Zac, same day: "if something changes even in the slightest I need to know... no changes, no harm no foul." My Tuesday-night run plus "rerun Thursday" was not wrong, only too early to be the first run.

**Why:** Tuesday data is stale (feed-only statuses), but updates are cheap and any change matters to his lineup and picks.

**How to apply:** Acknowledge an early card, note it in TASKS.md, wait. Run Wednesday after practice reports, rerun Thursday morning, and on each rerun report what changed vs the last run, even if small, or say nothing changed. Related: [[fantasy-football]].
