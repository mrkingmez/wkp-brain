- Write voice, music and effects as separate stems from the start so Zac can swap a track in one command, and write the pre-limiter mix as float, not clipped int16.
- Run-sheet effect dBs left effects near inaudible; normalize effects by peak, then place them.

## 2026-11-26 lesson (v4)
- Corner-mark crops must use the content area, not the file: the Premiere-ready clips carry their own letterbox bars, so a bottom-anchored crop kept the bar and the marks.
- A min-run rule must also cover the first run and any run created by the speaker lead; otherwise the QA finds a 0.2 s flash.
- Reuse unchanged render pieces by (in, out, description) to cut a rebuild from 10 minutes to about 2.

## 2026-11-26 lesson (v5)
- A single music file cannot serve both ends of a 31-minute video: use two cuts of the same file (intro from 0:06, the tail for the outro) and say so.
- Align the track's loud hit to the visual burst by delaying the track start, not by moving its 0:06 mark.
- Remix scripts that overwrite stems must be named per version, or the older version's stems are lost.
