Zac rejected the code-made Veterans Day cards (2026-11-10): "horrible, look like a 3 year old made them." The text layout was fine, the drawn artwork (flat gradient, geometric wolf head that read as a fox) was not.

**Why:** Pillow-drawn shapes cannot match photo or illustration quality on a public post.

**How to apply:** For public-facing graphics, get the artwork from an image model (Firefly via Zac's click, his credits shared with Matt, label as AI) or from owned assets, and use code only to lay text over it. Do not draw logos, mascots or scenes in code for posts. Kit pieces that are motion or UI (stickers, cards, counters) are a different case and have worked. See [[feedback-veterans-day-tone]].
