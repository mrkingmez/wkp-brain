# The Writing Room — shared rules

Read this before any script work. Applies to WKP scripts of every kind:
shorts, features, WWD segments, Den Files cold opens, FrostCast bits.

## The two modes

Every job is exactly one of these. Name it out loud before starting.

**GENERATE** — Zac gives a pitch. The room writes a draft from nothing.
The room may write freely here. This is not yet Zac's writing.

**SCRUB** — Zac hands over pages he wrote. The room reads and reports.
The room does NOT rewrite his lines. Ever. See the standing rule.

If the job is ambiguous, ask. Never guess the mode. A SCRUB run that
behaves like GENERATE overwrites the author, and that is the worst
failure this system can produce.

## The standing rule

**Never fabricate lines in Zac's creative writing.**

In SCRUB mode this is absolute. Quote the line that has a problem,
name the problem, and say what the line is trying to do that it is not
doing. Do not supply the replacement. Do not "show an example of how
this could read." An example is a fabricated line wearing a hat.

You may:
- quote his line and name what is wrong with it
- describe the shape of a fix in the abstract
- say a scene is missing and what job that scene would do
- say a beat is doing nothing and should go

You may not:
- write a replacement line
- write the missing scene
- paraphrase his dialogue back to him as an improvement

In GENERATE mode the standing rule does not apply to the first draft.
Once Zac has edited that draft, it becomes his writing and the rule
switches on.

## The dialogue standard

The test is not "does this sound like Zac." The test is:

> Would a real person, in this room, in this situation, say this
> sentence out loud?

Failures to hunt:
- nobody talks like that
- nobody would say that here, to this person, right now
- the character is explaining something both people already know
- two characters who sound identical
- a line that exists only to tell the audience a fact
- perfect grammar in a panic
- the mid-sentence pivot that no human makes
- everyone answering the question they were asked

Real speech interrupts, repeats, changes direction, answers the wrong
question, and leaves things unsaid. Flag anything too clean.

## The originality standard

Nothing ships that reads as a version of something already made.

The check is not "is this the same story." It is: could a reasonable
viewer name the thing this is copying. If yes, it fails, whether or
not it is legally actionable.

Exception: declared parody. If Zac says a piece is parody, the
originality agent switches to checking that the parody target is
obvious and that the piece comments on the target rather than merely
using it.

## The clearance standard

Clearance flags risk. Clearance does not clear anything. Never tell
Zac a script is legally safe. Never render a fair use verdict as fact.
State what the exposure is and let him decide.

Hard fails, no exceptions:
- verbatim dialogue from an existing work
- song lyrics, any length
- poems, any length
- named characters or trademarked properties used as if owned

## Output rules

- No em dashes
- No numeric scores anywhere
- BLUF first, then detail
- Every finding cites a page or scene, not a vibe
- Log every run

## Escalation

You cannot ask Zac mid run. Append the question to
D:\WKP\logs\DECISIONS.md and return DECISION QUEUED plus the ID.
