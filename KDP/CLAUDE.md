# KDP Publishing — Math Mystery & Puzzle Books

## What This Is
Kindle Direct Publishing venture using two BowesPaz/Toolshelf apps, both on
**Elite** tier (paid for by Zac's wife for her own business, shared access
confirmed via account screenshot 2026-08-24):

- **Genten Royalty** — generates math-mystery whodunnit workbooks for grades
  1-6: a story/case setup, suspect cards, math "clue sheets" covering
  multiple skill types (maps & scale, order of operations, number patterns,
  word problems, in/out function machines), an elimination mechanic, and a
  solution/case-report page. This is the primary niche.
- **Shigai Royalty** — murder-mystery-themed Sudoku puzzle books. Second
  product line under the same account, not yet explored hands-on.

Both apps generate the book content/interior; publishing strategy (which
topics, grade levels, how many titles, listing/keyword work) is on us, not
the app.

## Decisions Locked 2026-08-24
- **Series name: `Math Case Files`.** Not "Math Detective(s)" — that
  trademark is legally dead but Critical Thinking Co. still enforces it as
  a live brand on Amazon; a suppression fight isn't worth it on a book with
  no review history. Full naming rationale + 5 backup candidates in the
  Launch Guide.
- **Pricing: launch at $10.99, step to $12.99 after ~10 reviews, $13.99
  after ~25. Never below $9.99** — that's the 50%/60% royalty cliff.
- **Format: bundle 6-8 cases per book (~96-110 pages), black ink, 8.5x11.**
  Flat $2.84 print cost across that whole page range — bundling costs the
  same as a thin book but earns ~4x the royalty per sale.
- **Account: one KDP account (`zac@warriorkingproductions.com`), multiple
  pen names.** No second account — Amazon terminates accounts for that.
  Math Case Files and Shattered Empire (if self-published) can share the
  account under different pen names.
- **No Amazon/KDP API or MCP connection exists** — confirmed, Amazon
  doesn't publish one. Every publish action and every results pull is
  manual. This is a permanent constraint, not a current gap.
