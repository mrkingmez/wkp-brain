## 1. Market Research Summary

*(Full sourcing and the complete comp table live in this file's "Full
Research Appendix" at the bottom. This section is the part you act on.)*

### Naming: **Math Case Files**
Series brand = `Math Case Files`. Book title = the case name, subtitle
carries the keywords.

**Title template:**
`[Case Name]: [N] Math Mysteries for Grades [X]–[Y] | Read the Clues, Cross
Out the Suspects, Crack the Case — Math Puzzle Workbook for Kids Ages
[A]–[B] (Math Case Files, Book [N])`

**Why this name and not "Math Detective":** the federal trademark for MATH
DETECTIVE (Critical Thinking Co.) was legally cancelled in 2014 for
non-renewal — but Amazon doesn't check USPTO status, and Critical Thinking
Co. still enforces the name as a live brand. A brand complaint gets a new
listing suppressed for weeks before anyone reviews it, which is fatal for a
book with zero review history. Not worth the risk when a clean name exists.
Put `Math Case Files` in KDP's **Series** field — that's what links every
book you publish onto one series page, free, and it's the single highest-
leverage move a niche publisher makes.

### Description: use the template
A ready-to-fill listing description template — built from the actual
structure the closest indie competitors use (hook, premise, what's-inside
count, case list, keyword blocks, closer) — is in Section 4 below, ready to
paste into KDP per book.

### Pricing: **$10.99 to launch, $12.99 after ~10 reviews, $13.99 after ~25**
Never below $9.99 — that's the line between 50% and 60% royalty
($2.15/sale vs $3.15/sale on a 50-cent difference in list price). Bundle
6-8 cases into one ~96-110 page book rather than selling single 15-page
cases: black-ink 8.5x11 printing is a flat $2.84 from 24 to 110 pages, so a
bundled book costs the same to print as a thin one but earns roughly 4x
the royalty per sale.

## 2. How We Set This Up (start-to-first-sale sequence)

1. **Confirm Genten Royalty's real output** (today/tomorrow, hands-on).
   Generate one real case end to end and check: actual page count per
   case, file format it exports (PDF? Word? does it need external
   layout work?), whether art/suspect cards are color or safely B&W,
   and what "different variants" actually means in the option set.
2. **Lock the account setup** (see Section 3 — no new account needed).
3. **Pick 2-3 grade/theme combinations** using BowesPaz's free KDP Niche
   Finder tool rather than guessing — this is free and already in your
   Toolshelf account.
4. **Generate Book 1**: 6-8 cases bundled into one manuscript, same
   grade band, one theme/setting thread if Genten supports that, or a
   mixed-case book if not.
5. **Build the cover** — series template so every future book reuses it
   (BowesPaz's free AI Image Creator tool can help here, or Firefly).
6. **Format the interior for KDP's actual page requirements** (Section 5
   covers exact specs — trim size, margins, bleed).
7. **Write the listing** using the Section 4 template.
8. **Publish, set price at $10.99**, submit for review (typically 24-72
   hours for KDP's first review).
9. **Start the Sunday pull** the following Sunday — see Section 6.

### Day 1 (tomorrow) — what to actually do
**Realistic Day 1 output: one case run-through, not a published book.**
Publishing same-day isn't realistic — you don't yet know Genten's real
page count, haven't picked a niche via the Niche Finder, and don't have a
cover built. Day 1 goal:
- Generate 2-3 sample cases in Genten to see the real option set and
  page count (this answers the #1 open unknown blocking everything else)
- Run the KDP Niche Finder once, pick a tentative grade/theme
- Confirm the KDP account/pen-name setup (Section 3 — this takes 10
  minutes, do it Day 1 regardless of the rest)

Once page count and niche are confirmed, Book 1 (6-8 bundled cases) is
realistically a 3-5 day build after that, not same-day.

## 3. Account Setup — the email question, answered

**Use `zac@warriorkingproductions.com`. Do not create a second KDP
account.**

Amazon allows **multiple pen names on one KDP account** — up to 3 per
Author Central profile, more available on request — with no requirement to
separate them by account. Each book you publish can carry a different
author/pen name, and they don't get cross-linked publicly unless you choose
to link them via Author Central. This means:
- `Math Case Files` books can publish under one pen name (a kid-friendly
  imprint name, not "Zac" — see Open Items)
- Shattered Empire Book 1 can publish under a different pen name later,
  same account, whenever that's ready
- **Creating a second KDP account is a real risk** — Amazon has terminated
  accounts for exactly this ("multiple accounts" policy violation). One
  account, multiple pen names, is the correct and only safe structure.

Source: KDP Community threads on multi-pen-name accounts confirm this is
standard practice; Amazon's own KDP terms restrict one account per
publisher entity, not one account per book/genre.

## 5. Full KDP Submission Walkthrough

*(Verified against current KDP category/keyword rules as of 2026-08-24;
KDP's exact screen layout shifts periodically — the fields below are
stable, the exact button placement may not be.)*

### A. Title & Series Info
- **Book Title** — the case name (e.g. "The Treetop Garden Village")
- **Subtitle** — the keyword-loaded template from Section 1
- **Series** — `Math Case Files`, and set this book's number in the series
- **Edition number** — leave blank for a first edition
- **Author** — the pen name (see Section 3/Open Items)
- **Contributors** — none needed unless an illustrator is credited separately

### B. Description
Paste the filled Section 4 template, formatted with `<b>`/`<ul>` tags.

### C. Publishing Rights
"This is not a public domain work" → you own the rights (Genten's terms of
service should confirm generated content is yours to publish — **flagged
as an Open Item below, verify before publishing anything**).

### D. Keywords (7 fields, 50 characters each)
Pick 7 real search phrases, not single words. Draft set based on the
description research:
1. `math puzzle book for kids grades 3 4`
2. `math mystery workbook elementary`
3. `homeschool math enrichment workbook`
4. `detective math activities kids`
5. `summer bridge math workbook`
6. `math word problems grade 3`
7. `math logic puzzles for kids`
*(Adjust grade numbers per the actual book; these are placeholders.)*

### E. Categories (3 slots, paperback and ebook get independent slots)
Pick from Amazon's own live category tree (not a general BISAC code —
that changed in 2023; you now pick directly from what shoppers browse).
Target the deepest, most specific matching shelf in:
- Children's Books → Education & Reference → Math
- Children's Books → Activities, Crafts & Games → Puzzles
- Education & Reference → Workbooks

Use the free KDP Niche Finder tool before finalizing — it shows real
competition levels per category, don't guess.

### F. Paperback Details
- **Trim size**: 8.5" x 11"
- **Interior**: Black & white, standard paper
- **Bleed**: No bleed (unless art runs to the page edge)
- **Cover finish**: Matte (standard for workbooks)
- **Page count**: whatever the bundled manuscript comes to (target
  96-110 to stay in the flat $2.84 print-cost band)

### G. Pricing
- List price: **$10.99** to launch (see Section 1)
- Territories: All marketplaces
- Confirm the royalty preview shows 60% before publishing — if it shows
  50%, the price is under $9.99 somewhere in the flow, fix it before submit

### H. Content Upload
- Interior manuscript as PDF (Genten's export format — confirm this is
  print-ready, KDP-compliant margins, during the Day 1 hands-on session)
- Cover as a separate KDP cover-template file (KDP's Cover Creator can
  build one, or upload a print-ready wraparound cover PDF)

### I. Review & Publish
- Preview using KDP's online previewer before submitting — check every
  page renders correctly, nothing's cut off at the trim edge
- Submit for review: typically 24-72 hours for KDP's compliance check
- Once live, note the ASIN in the Tracker (Section 7)

## 6. The Sunday Pull & Morning Brief

**No API exists for KDP** (confirmed — Amazon does not publish a KDP API;
third-party "integrations" are all browser scraping tools, not something
to build this system on). Every number has to be pulled by hand from the
KDP dashboard.

**Every Sunday:**
1. Log into KDP, pull for each published title: units sold (period + total),
   royalties (period + total), current BSR, review count, star rating
2. Save to `D:\WKP\data\kdp-manual-YYYY-MM-DD.md` — same convention as
   Etsy's Friday manual file, so jarvis's closed-loop rule can find it
3. Update `Tracker.csv` (Section 7) with the same numbers

**Morning brief:** now handled automatically — `kdp-director` is a real
agent in the roster, and jarvis's routing table now includes KDP. As long
as kdp-director logs its work (same as wwd-director and etsy-director do),
jarvis's daily/status runs will pick it up without anything extra needed
from you.

## 8. What's Missing — Gap Check Before This Runs to Standard

Real gaps, not busywork — each of these blocks something above:

1. **Genten Royalty hasn't been run hands-on.** Every page-count, pricing,
   and bundling number in this guide assumes the one 15-page sample holds.
   This is the single biggest unknown — do this first.
2. **Genten's content-ownership terms haven't been checked.** Before
   publishing anything generated by the app, confirm BowesPaz's terms of
   service actually grant you full commercial publishing rights to the
   output — most generator tools do, but this hasn't been verified, and
   it's the kind of thing that's expensive to find out late.
3. **No pen name picked yet.** Section 3 covers the account structure;
   the actual name (imprint/author name for the Math Case Files books) is
   still an open decision.
4. **No cover built or template chosen.** Needed before any book can be
   submitted.
5. **Genten's export format is unconfirmed** — whether it hands you a
   print-ready PDF that meets KDP's margin/bleed requirements as-is, or
   needs manual layout work first.
6. **No production skill exists yet** (unlike Etsy, which has
   listing-factory-weekly-batch-skill etc.). Once the Genten workflow is
   understood hands-on, this is worth building so future books don't need
   a from-scratch manual walkthrough every time.
7. **No marketing agent exists in this system yet** to connect kdp-director
   to — you mentioned wanting this connected to "the marketing agent"; as
   of this build, no such agent has been built for any venture. If you want
   one, that's a separate, explicit build — flagging rather than assuming.
8. **Shigai Royalty is completely unexplored** — scope was deliberately
   deferred to after Genten's first batch, per the original plan.

### Trademark Detail
- MATH DETECTIVE, Serial 78907253, Reg. No. 3294004, owner Critical
  Thinking Company — registered Sep 18 2007, **cancelled Apr 25 2014**
  (Section 8 non-renewal). Even when live, "MATH" itself was disclaimed —
  they never had rights to the word alone. Source:
  https://tsdr.uspto.gov/statusview/sn78907253
- Despite the dead registration, Critical Thinking Co. still marks Math
  Detective® with the registered symbol and maintains an IP attorney of
  record — a brand complaint to Amazon suppresses a listing before
  anyone adjudicates whether the mark is actually enforceable. Not worth
  testing on a book with no review history.
- Two other sellers already use "Math Detective(s)" as a title (not
  registered, but crowds the search results either way).
- Not fully verified: whether Critical Thinking Co. holds any newer
  trademark filings beyond the one confirmed-dead registration — USPTO's
  bulk search wasn't fully accessible during research. Doesn't change the
  recommendation (avoid the name regardless), but noting the limit.
