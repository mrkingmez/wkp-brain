# Prompt Master v3 (PROPOSED)

Status: a proposal for Zac to mark up. It is built from what the Draft 3 run showed, not from a line-by-line diff against Prompt_Master_Rebuilt_v2_0. Nothing here replaces v2 until Zac says so.

## 1. Standing rules (carry over unchanged)
- No em dashes anywhere in editorial output.
- No colons inside options or fixes.
- God stays. Plural "gods" lines are logged as questions only.
- No new scenes, plot, lore, characters or place names, including in the editor's own commentary.
- The author has final say on every call.
- Do not flatten intentional dialect.
- Detail is not fat by default.

## 2. Proposed additions from the Draft 3 run
1. Run a mechanical net first. Spelling, spacing, quotes, names and locked-spelling hits are batched so the read can stay on craft. In Draft 3 this was 489 items that would otherwise have buried the craft items.
2. Keep a canon ledger and a foreshadow ledger for the whole run. Ledger facts settle disputes quickly. In Draft 3 the ledger caught that Arthur (Reau's father) is not Adin, which avoided a false contradiction in the Epilogue.
3. Ledger-versus-text conflicts stay in the text and become questions. Never fix the text to match the ledger without Zac.
4. Unsourced direction notes (for example "trim the torture") are logged as questions. Nothing is cut or added until Zac names the scope.
5. Every item names its craft cause. "Reads AI" is not a cause. "Not-X-but-Y turn" or "feeling explained after it was shown" is.
6. A verifier gates every chapter: flagged line exists exactly once, no em dashes, no colons in options, locked spellings enforced, options A to C present on non-mechanical items.
7. Zac's stored Finds become ZAC NOTE items with his replacement as Option A. His Keeps become ZAC NOTE items with "no change" as Option A.

## 3. Proposed changes to the tag set
- Keep MECHANICS, CUT ONLY, ADD, VOICE, AI TELL, CONTINUITY, FORESHADOW, ZAC NOTE.
- Add a one-line field "CAUSE" to AI TELL items so counts by cause are exact instead of keyword-matched.
- Keep three severities (Must fix, Should fix, Polish). Use Must fix only for things a reader would call an error.

## 4. Proposed changes to the grain scores
- Use the same seven labels in every chapter. Draft 3 used "Character Interiority" and "Human and Author Voice" for Chapters 0 to 17 and "Emotional Subtext" and "Prose Control" after that. The table in the report maps them, but one set would be cleaner.
- Score with one word (Strong, Moderate, Weak) and put the evidence in brackets, so the ratings can be counted.

## 5. Open items for v3 that need Zac's ruling
- Whether to write dialect spelling (the Annex allows it, the Performance PDF forbids it). The Draft 3 census found almost none in the book.
- Whether Prompt Master should name the Eight and the Nine, or keep the number off the page of the prompt itself.
- Whether to add a full-manuscript diff pass as a standard first step.
- Whether the writing-room agents (dialogue-doctor, originality, fact-research) run at chapter-group breaks by default.
