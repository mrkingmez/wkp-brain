# RUBY TWO — WWII Short Film

## What This Is
Warrior King Productions short film. WWII daylight bombing mission, 15-20 minute target runtime. Standalone venture, not a Post-Production client job — WKP is the production company here, not the service provider.

Dual purpose, both real:
1. Learn the full production workflow end to end, start to finish
2. Portfolio proof-of-concept for Warrior King Productions AI filmmaking

## Assets That Already Exist (in Drive — reference, not duplicated here)
- **RUBY-TWO-Production-Bible.docx** — module-based production plan. Documents BOTH pipelines: traditional (Blender / UE5 / After Effects / Premiere / Resolve / Audition) and AI-assisted. Authoritative for how the film gets made.
- **RUBY-TWO-Screenplay.docx** — complete, 14 scenes. Locked unless deliberately revised.
- **Bombing-Mission-Beginner-Deep-Dive.md** — beginner's tutorial covering the core tools. Written for Zac's own ramp-up.

Read the Production Bible before proposing anything about workflow or pipeline. It already answers most process questions.

## Casting / Voice
- Principal roles: Zac plus friends
- Everything else: ElevenLabs

## Current Status
Pre-production. Bible and screenplay written; no production started as of August 2026.

The same bottleneck affecting Watershed applies here — Zac has the tools for the visual quality he wants but is still building the skill to execute it, with zero outsourcing budget. Expect this to move slowly and in modules rather than as one continuous push.

## Working Notes
- This is a learning project as much as a deliverable. Speed is not the metric; finishing a module correctly is.
- The two pipelines in the Bible are alternatives, not a sequence — don't blend traditional and AI approaches within the same module without a deliberate call.
- Blender mesh distinction applies: cinematic mesh (non-manifold fine, arbitrary scale) is what this project needs. Print-ready rules do not apply here.
- Pre-production character reference boards (turnaround sheets, storyboard panels, camera diagrams) were scoped but deliberately deferred until active production starts. Don't build them early.
